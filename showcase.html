⌨️ 新增命令

origami dieline parse <file>
解析 PDF/EPS/SVG/FOLD 文件
origami bind add <model> <face> <artwork>
绑定 artwork 到指定面
origami render single <model>
商业级 3D 渲染
origami template generate <name>
生成盒型模板，支持 --thickness 参数

💡 使用示例

# 生成 100×60×30mm 邮寄盒，厚度1mm
$ origami template generate mailer -w 100 -h 60 -d 30 -t 1 -o mailer.fold

# 渲染 300 DPI 商业图片
$ origami render single mailer.fold -o mockup.png --dpi 300 --shadow --preset print

# 绑定设计图
$ origami bind add mailer.fold 0 artwork/front.png
$ origami bind add mailer.fold 1 artwork/back.png
